    Security and integration

    Vendor-Neutral Telemetry

    The same number means the same thing on every part.

    • Health metric: measured slack as a share of the clock period, per logic-element link.
    • One telemetry schema, one set of thresholds, one aging model.
    • Vendor-specific integration handled by Fluid Silicon.
    • Fits your existing monitoring; nothing leaves your network.

    Two layers

    What you see and act on is identical on every vendor. What differs between vendors is handled beneath it.

    Scheduled, Handshake-Gated Changes

    Change control your operations team will recognize.

    • Read-only by default; tuning and repair enabled by policy.
    • Changes run only in maintenance windows you schedule.
    • Coordination per device, per server or fleet-wide.
    • A handshake on every action.

    Deterministic changes

    Every change is scheduled, approved and re-measured within a second, so the state of the fleet is always known.

    FAQ

    Common questions.

    Sensor architecture, deployment mechanics and calibration methods are shared with evaluation partners under NDA.

    How does it fit our monitoring?

    Telemetry follows one vendor-neutral schema, so it lands in the monitoring you already run. The platform is deployed on your site.

    Do we need to change our design?

    Your RTL is not changed. What integration needs from your team, a small resource reservation beside your design, is planned during evaluation.

    How are changes controlled?

    Read-only is the default. Tuning and repair are enabled separately by policy, run in windows you schedule, and every action is handshake-gated.

    Can we coordinate changes across a rack?

    Yes. Operating points can be coordinated per device, per server or across the fleet.

    Which devices are supported?

    AMD 7-series, UltraScale and UltraScale+ today, with select Altera Agilex 7 devices. Stratix 10, Arria 10 and Versal AI Core are in development.

    What about cards from two vendors in the same rack?

    They report the same metric, the same schema and the same thresholds. That is the point of the vendor-neutral layer.
